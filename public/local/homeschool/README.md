# Homeschool dashboard (local_homeschool)

Parent/teacher dashboard for planning and managing day-based coursework across Day sections courses.

## Requirements

- Moodle 5.2–5.3 (see `version.php`)
- [format_daysections](https://github.com/YOURUSER/moodle-format_daysections) 1.0.0+

## Install

1. Install and enable **Day sections** first
2. Place this plugin in `local/homeschool`
3. Visit **Site administration → Notifications** to finish install
4. Open **Homeschool** from the primary navigation (capability required)

## Features

- Dashboard of children, Day sections courses, and upcoming timeline reminders
- Day page to review activities across courses for a given day
- Set or clear timeline reminder dates in bulk
- Shift schedule forward/back with preview and undo
- Add or delete activities from the day view (returns to the day page after editing)
